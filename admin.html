Connect to GitHub

Changes you save here — including uploaded images — are committed directly to your GitHub repo, so they go live for every visitor after your host rebuilds (usually under a minute). Create a token at github.com/settings/tokens (fine-grained, scoped to just this repo, with Contents: Read and write permission). The token is stored only in this browser's local storage — never committed to the repo.
